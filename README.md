## Modernizing Electricity Billing System Using Java
## 📌 Project Overview

The Electricity Billing System is a Java-based application developed to automate the process of electricity bill generation and management. The system allows users to manage customer details, meter readings, electricity consumption, bill calculation, and payment information.

The main purpose of this project is to reduce manual work, minimize calculation errors, and provide an efficient way to manage electricity billing records.

## 🎯 Objectives
Automate the electricity billing process.
Manage customer information efficiently.
Calculate electricity consumption based on meter readings.
Generate electricity bills automatically.
Maintain customer billing and payment records.
Reduce manual calculation errors.
Provide an easy-to-use billing management system.

## 🛠️ Technologies Used
Java
Java Swing
MySQL
JDBC
Eclipse IDE

## 🚀 Features
## 👤 Customer Management
Add new customer details.
View customer information.
Update customer records.
Search customer details.
## 📟 Meter Reading
Enter previous meter reading.
Enter current meter reading.
Calculate total electricity units consumed.

Formula:

Units Consumed = Current Reading - Previous Reading
